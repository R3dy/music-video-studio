# UI mockups

Visual mockups for the views defined in [`docs/specs/`](../specs/). Each image is named after the area spec it illustrates, so `NN_Area_Name.png` pairs with `docs/specs/NN_Area_Name.md`. When an area needs more than one image, add a suffix such as `06_Cast_and_World_V16.png`.

Mockups are design proposals. Where a mockup and a spec disagree, the spec and PRD win until the spec is updated.
